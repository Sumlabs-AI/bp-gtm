How to label

  • Label what the text says. If it's only a name ("McDaniel - Battery"), tick battery and pick can't tell for the action.
  • Gas line for a generator: tick standby generator, action = supporting work only.
  • Portable hookup = inlet box, interlock kit, or manual switch for a portable generator.
  • Transfer switch with a generator = standby generator. A FranklinWH/Tesla "gateway" or "backup switch" = battery.
  • Solar + battery on one permit: tick both.
  • Property: use Austin's "Residential/Commercial" class if the text doesn't say. A cell tower or AT&T site = commercial.
  • Not sure? Choose your best guess and write a note.
